# Mob Morph (Fabric 1.20.1)

Превращайся в любого моба: другие игроки видят настоящего моба с его размерами, а у тебя — его здоровье,
урон, скорость и способности.

## Готовый .jar без установки Java
1. Создай репозиторий на github.com и залей в него всё содержимое папки (папку `.github` тоже!).
2. Вкладка **Actions** — дождись зелёной галочки (3–5 минут).
3. Готовый мод: вкладка **Releases** (справа на главной странице репозитория) → `mobmorph-1.0.0.jar`.
   Либо Actions → запуск → Artifacts → `mobmorph-jar`.
4. Положи jar и Fabric API 0.92.2+1.20.1 в папку `mods` (у всех игроков), Fabric Loader для 1.20.1.

## Управление
- **H** — меню со всеми мобами (поиск, страницы, колесо мыши листает; наведи на моба — увидишь его способности)
- **R** — способность моба
- **G** — вторая способность (эндермен: взять/поставить блок; ведьма: выпить зелье; эндер-страж, хранитель, заклинатель)
- **V** — полёт для летающих мобов (Пробел — вверх, Shift — вниз; ещё раз V — выключить)

Команды (нужен оператор): `/morph <моб> [игроки]`, `/morph off [игроки]`.
В `MobMorph.java` константа `MENU_REQUIRES_OP` — ограничить меню операторами.
